# 全量验证与持续维护

## 当前交付与证据范围

2026-10-08 已完成原任务目录备份、订阅接入、关闭自动增删任务和锁定依赖部署。现有 51 个任务均有源码、配置与现存日志检查结果；互助 Shell 与 79 个公共/根目录依赖纳入文件哈希清单。清单见 [状态记录](../maintenance/status.json)、[源码清单](../maintenance/inventory.json)。

这里的“检查完成”不等于 51 个任务全部实测成功。49 个原任务包含混淆代码，部分辅助模块尚未完整还原；这些旧入口不得带凭据批量执行。已经审阅的只读探针与一个签到动作使用单账号顺序验证。原始响应、账号、缓存和日志保留在本地，公开状态只保存脱敏结果。

本轮实际查询：用户信息返回 `retcode=1001` 未登录；京豆明细 HTTP 403；农场入口 `code=2`；种豆入口 `code=1`；庄园任务列表返回成功，但签到动作返回 `code=2018`，未确认业务成功。参数和签名差异仍待修复。不能把这些结果推广为全部 Cookie 失效，也不能归为活动结束。

现有庄园日志保留了签到、浏览获得游戏币的成功证据，因此归为“部分可用”，本轮签到失败另外记录。普通助力尚无有效非本人目标；删除、评价、价保、兑换、竞猜等没有作为实测动作执行。

## 本轮修复

- 京豆详情改为可读查询代码。失败、格式异常、分页不完整或达到上限均显示“未知”；只有完整成功查询的空明细才能计为零。修复后真实查询受阻时已确认输出未知。
- 资产统计查询失败时停止默认零值汇报，并保留上次缓存。模拟响应验证了汇报与缓存写入保护，资产接口业务仍然阻塞。
- 庄园任务列表/详情空值返回空数组；工位分配改为有限循环，缺失列表、操作未明确成功、刷新失败或状态未变化时停止。未实测合成、购买或兑换。
- 删除公共 Cookie 模块中硬编码的“MCK 全部失效”提示。
- 审阅路径使用统一请求模块：两秒间隔、单次十秒超时、次数及总时间上限，只有超时或 5xx 重试一次；403、未登录和风控停止本次路径。只允许明确列出的京东官方域名，不跟随重定向，不向外部签名服务发送 Cookie。

统一请求保护仅接入已经修改的统计与庄园路径，不代表其余原始混淆脚本已经完成传输审阅。业务恢复必须追加真实成功证据；模拟测试通过只表示相应代码缺陷已修复。

## 手动验证工具

```sh
npm run inventory
npm run verify

# 默认仅展示清单。凭据文件和输出目录必须位于仓库之外。
node tools/probe-jd.mjs
node tools/probe-jd.mjs --run --cookie-file /private/JD_COOKIE.txt --output-dir /private/jdpro-probes

# 默认关闭；只验证任务列表明确返回的 SIGN，不抽奖、不兑换。
node tools/run-daily-jd.mjs
node tools/run-daily-jd.mjs --execute joy-sign --cookie-file /private/JD_COOKIE.txt
```

只读探针的农场/种豆请求是有限的入口检查，尚未接入全部旧签名参数。因此其失败不足以证明原始脚本活动失效。任务列表成功也不构成奖励到账证据。禁止绕过风控或凭据失效后反复重试。

## 发布与部署

本地检查与回归通过后，先推验证分支并等待 GitHub Actions。CI 成功后再发布到 `main`，等待该提交的 CI，运行原订阅同步。同步工具逐文件核对内容，在原目录写入 `.jdpro-deployment.json`，记录源码提交号及文件哈希；随后核对青龙日志和实际运行结果。

同步或依赖安装失败会恢复本次变更前的受管源码；npm 安装失败时恢复原 Node 依赖目录。账号缓存、本地配置和任务时间不参与替换。运行验证发现回归时，从维护前备份或上一发布提交同步源码并复核；不要用失败查询更新账号缓存。Python 依赖安装涉及容器内的包环境，如失败须核查容器依赖状态。

## 日常维护规则

当前聊天已建立每天上海时间 10:00 的维护任务。先读取新增日志，只复查发生变化或已修复的路径；每周一核对完整文件清单。故障分类为可用、部分可用、认证阻塞、配置缺失、接口异常、活动结束、未验证。重复且无变化的失败保持静默，修复完成、状态变化或需要处理时通知。

新活动以名称、官方入口与活动 ID 去重，并核实规则日期、账号资格和实时响应。已审阅的 [翻倍挑战规则](https://h5.m.jd.com/pb/013640630/2MsVcneB4n8Nf77eHN1DPNcMurkx/index.html) 有效期截止 2024-12-31；[抖音好评分享规则](https://pro.m.jd.com/mall/active/2KZFDNAyKERgfwuqf24DSXkBHXwY/index.html) 截止 2026-09-20，两者均保留在排除记录中。没有把仍可访问的旧网页识别成新活动，也没有凭此停用无法对应活动 ID 的现有任务。

本轮尚无经官方规则及当前账号业务响应共同验证的新免费日常活动，所以没有创建或启用新的活动任务。新增脚本必须可读、复用已验证模块、记录来源/配置/退出条件，先模拟后单账号验证，发布后仍默认关闭。NAS 不可访问、认证不足、缺少助力目标或未审阅传输路径时，记录具体阻塞并在条件恢复后继续。
