## 发布与部署

本地检查与回归通过后，先推验证分支并等待 GitHub Actions。CI 成功后再发布到 `main`，等待该提交的 CI，运行原订阅同步。同步工具逐文件核对内容，在原目录写入 `.jdpro-deployment.json`，记录源码提交号及文件哈希；随后核对青龙日志和实际运行结果。

同步或依赖安装失败会恢复本次变更前的受管源码；npm 安装失败时恢复原 Node 依赖目录。账号缓存、本地配置和任务时间不参与替换。运行验证发现回归时，从维护前备份或上一发布提交同步源码并复核；不要用失败查询更新账号缓存。Python 依赖安装涉及容器内的包环境，如失败须核查容器依赖状态。
